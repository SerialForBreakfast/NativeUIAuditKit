## What confirms the prototype?

- The corpus contains verified native focus labels and a qualified visible HCF condition.
- The model improves correct selections over the pinned comparison on matched development cases.
- Wrong selections do not increase on those cases.
- The candidate loses no frozen previous successes.
- Frozen models and thresholds pass the reserved audit without further tuning.
- Core ML preserves preprocessing and decisions within recorded numerical tolerances.
- TTR can load the experimental package optionally and return case-linked shadow results.

These conditions establish an experimental prototype, not navigation safety.
Report model accuracy and abstention together. Do not hide failures by rejecting most screens.
Do not set a production threshold from this plan.

If oracle crops work but proposals fail, improve proposals rather than reject HCF learning.
If crops work but full-screen detection fails, inspect scale, localization, and data balance.
If training fits but reserved scenes fail, inspect template and artwork coverage before adding epochs.
If neither model fits verified examples, inspect preprocessing, labels, optimization, and cue resolution.
If 2 data-growth stages give no useful gain, stop expansion and diagnose.
No single failed model proves that HCF is untrainable.
