## Architecture decision

| Choice | Benefit | Current decision |
| --- | --- | --- |
| Existing rules | No model download; already proposes Home outlines and Settings rows | Keep as optional review assistance |
| Existing model with a profile input | Can share visual features | Defer until matched profile data exists; profile alone must not imply focus |
| Rules plus model | Can expose disagreements and rank proposals | Prefer this next comparison; retain separate outputs before testing a combined decision |
| Separate HCF model | Can specialize without changing ordinary predictions | Use only if measured gains justify another artifact and inference cost |

HCF asks which control appears focused in 1 image. The transition model asks whether focus changes between 2 images.
Do not use transition scores as single-image focus scores.
Rule confidence and model scores are not interchangeable probabilities. Do not average them without a measured comparison.
