# HCF335 — resumable focus batches

Owner: Maximum-mini-NUIAK.

## Scope

Portability follow-up: [HCF336 / ADR-0025](../ADR-0025-Portable-Experiment-Runner.md).
This runner remains a NUIAK-local prototype until that migration passes. Do not describe it as a standalone distribution.

Build a bounded runner for unattended generation with current TTR source.
Keep native HCF capture separate from authored effects.
Do not start training, change model selection, or install a scheduler.

The initial adapter uses `render-headless-screen.swift`.
It supports shelf, grid, hero detail, and top navigation layouts.
The inspected source has no HCF switch or seed argument.
An empty artwork folder uses renderer placeholders. This qualifies execution, not visual diversity.

## Contract

- Freeze jobs, renderer hash, artwork hashes, and runner hash before execution.
- Use project-local paths and a new output directory.
- Permit at most 100 jobs per plan.
- Compile once per campaign. Reuse the compiled renderer after checking its hash.
- Run 1 renderer at a time under a shared runner lock.
- Start at low process priority.
- Check free space and host load before each job.
- Bound each operation and total output size.
- Save each job result with atomic checkpoints.
- Check PNG hashes, dimensions, decoded pixels, focus identity, and authored bounds.
- Stop on failure. Preserve partial files and logs.
- Resume complete jobs without rendering them again.
- Require explicit reconciliation after an interrupted running job.
- Keep all results development-only. Do not infer native focus labels.

The lock coordinates this runner only. It does not reserve TTR, a Simulator, or unrelated training processes.
Host load is a coarse admission check, not a GPU reservation.
The child inherits the lock. A parent crash cannot immediately admit another renderer.
Timeout and cancellation terminate only the runner's child process group.
Failed compilation keeps its partial executable. A later attempt uses a new name.

## Commands

Use `.venv-yolo/bin/python scripts/focus_batch_harness.py` with these actions:

1. Use `plan --renderer SOURCE --assets DIRECTORY --jobs JSON --output PLAN`.
2. Use `init --plan PLAN --root NEW_DIRECTORY`.
3. Use `start --root DIRECTORY --max-jobs 10` for detached execution.
4. Use `status --root DIRECTORY` to read the checkpoint.
5. Use `run --root DIRECTORY --max-jobs 10` for a foreground continuation.
6. Use `cancel --root DIRECTORY` to request cancellation.
7. Use `reconcile --root DIRECTORY` after an interrupted worker.

Jobs contain `id`, `layout`, and optional `focusID` values. Use `null` for the renderer's default focus.
The `focusID` key is required even when its value is `null`.
Remove only the campaign's `STOP` file before an explicit restart after cancellation.
No automatic retry follows a failed job. A later explicit run uses a new attempt directory.
Reconciliation accepts complete validated files. It marks incomplete attempts as interrupted.
The next run retries interrupted jobs, not completed jobs.

The `start` receipt means launched, not accepted. Check worker logs if the checkpoint does not advance.
The sandbox can deny low-priority scheduling. Use scoped approval; do not bypass the check.
An existing approved scheduler can call `run`. This task installs no recurring service.

## Verification

Test pins, collisions, invalid jobs, resource deferral, exclusive access, cancellation, interruption, changed results, timeout, and unsupported versions.
Run 4 real layouts in 2 batches. Verify that the second batch preserves the first batch's files.
Run the offline Swift build and tests once after integration. Preserve any sandbox failures separately.

## Native HCF extension

Maximum-mini-NUIAK needs the committed command contract before building the native adapter.
The adapter needs exact-target readiness, original-profile recording, verified restoration, and restart recovery.
It also needs observed focus labels, capture intervals, and per-frame profile evidence.
Keep the existing 48-image pilot and its family exclusions. Add verified no-focus and distracting-border cases separately.
Do not let authored results satisfy native HCF acceptance.
