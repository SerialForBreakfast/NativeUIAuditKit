## Pilot scorer contract

The scorer compares methods against verified focus truth on identical membership.
It replaces no existing report. `report_hcf334.py` still compares model output with saved rule proposals.

### Truth input `hcf-pilot-truth-v1`

Each frame has these fields:

- `frame_id`, `sha256`, `width`, `height`
- `profile`: `default` or `high_contrast`
- `family` and `scene`. The group key is the pair of these fields.
- `role`: `development` or `reserved`
- `focus.state`: `focused`, `no_focus`, or `uncertain`
- `focus.box` for `focused` frames: top-left pixel `x, y, width, height`

### Method input `hcf-pilot-predictions-v1`

Each method file names 1 method and has 1 entry for each truth frame:

- `frame_id` and `sha256`
- `decision`: `select` or `abstain`
- `box` when the decision is `select`
- Optional `latency_ms`

### Outcomes

| Truth | Decision | Outcome |
| --- | --- | --- |
| focused | select, IoU ≥ 0.5 | correct |
| focused | select, IoU < 0.5 | wrong_focus |
| focused | abstain | miss |
| no_focus | abstain | correct_abstention |
| no_focus | select | wrong_focus |
| uncertain | any | excluded and counted |

The 0.5 IoU threshold matches the HCF334 agreement threshold.

### Validation

- Reject a method file when its frame set or hashes differ from the truth file.
- Reject duplicate frame IDs, non-finite numbers, boxes with no area, and boxes outside the image.
- Reject a `select` without a box and an `abstain` with a box.
- Count repeated image hashes inside 1 group once for group metrics. Report the duplicate count.

### Output

- For each method and role: outcome counts, wrong-focus rate, miss rate, abstention rate, coverage, and no-focus specificity.
- Mean IoU for correct selections.
- Group counts and group-bootstrap intervals with a fixed seed.
- Warm latency p50 and p95 when every frame has a latency value.
- Paired comparison for each method pair: frames where 1 method is correct and the other is not.
