## Priority and experiments

Run the first 5 comparisons from shared pilot inputs before expanding collection.
Reuse each prediction across applicable reports. Keep selection, change, localization, and settling results separate.

| Order | Test | Controlled comparison | Decision |
| --- | --- | --- | --- |
| 01 | Profile benefit | Same scenes, actions, seeds, and controls under Standard versus HCF | Determine whether HCF improves selection and movement recall |
| 02 | Rules versus models | Pinned TTR rules, shipped FocusRing, and retained transition model on compatible tasks | Choose which existing method benefits from HCF |
| 03 | Wrong selections | Focused versus unfocused controls with bright artwork or borders | Reject benefits that increase false selections |
| 04 | Small controls and position | Paired profiles by measured control size and screen region | Find where HCF recovers missed small or edge controls |
| 05 | Boundary evidence | Original crops versus added boundary detail; preserve original pixels | Determine whether crops remove the useful HCF outline |
| 06 | Content without movement | Fixed focus with artwork changes under both profiles | Check whether HCF reduces false change decisions |
| 07 | Scroll without movement | Fixed focus during scrolling versus stationary focus movement | Separate outline tracking from scene movement |
| 08 | Settling | Timestamped before, intermediate, and settled frames under both profiles | Measure premature-ready decisions and detection delay |
| 09 | Clipping and neighbors | Matched visible fractions and identical adjacent artwork | Measure wrong selections near clipping and shared borders |
| 10 | Mode uncertainty | Known correct mode, unknown mode, and stale mode metadata | Check that uncertain mode cannot produce false confidence |
| 11 | Conservative combination | Existing model, HCF rule, and a frozen agreement-or-abstain rule | Test assistance without navigation authority |
| 12 | Reversal and repeats | Forward, reversed, and repeated-frame predictions | Detect direction bias and false changes on identical inputs |
| 13 | Authored versus native | Matched native HCF and authored borders with fixed bodies | Find which synthetic cues fail to transfer |
| 14 | Office transfer | Reviewed HCF-end frames versus earlier reviewed real interactions | Test descriptive transfer; do not claim causal profile benefit |
| 15 | Conditional training choice | Shared model with HCF examples versus HCF-specific correction at equal budgets | Select training only if earlier errors justify it |
