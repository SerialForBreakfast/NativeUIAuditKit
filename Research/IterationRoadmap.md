## Interfaces, verification and coordination

Use the [common worker contract](WorkerWorkflow.md) and
[change-scoped verification](IterationEfficiency.md). A reviewed interface enables
downstream software without waiting for a complete upstream feature. Artifact integrity,
source eligibility, integration and model quality are independent outcomes. Report all
four; synthetic tests cannot establish live or model qualification.

Focused tests during development; required full offline checks once at integrated
code handoff. Prose-only changes use content/link/diff validation. Full corpus checks
belong at freeze; reuse unchanged evidence with exact dependencies. Record timing
rather than assuming more or fewer tests improves productivity.

For a producer repair, send one typed failure with exact build/job/request identities,
expected result and known downstream gaps. Require evidence at the actual failed
boundary, then one changed-candidate smoke through intake and postflight under
explicit authority. No unchanged retry, generic signing/storage repair or idle polling.
An absent SMB mount blocks publication only. Share only cross-project consequences;
local iOS, quality planning and dataset progress stay here. Publication, readback,
peer acknowledgment and completed integration are four different claims.
