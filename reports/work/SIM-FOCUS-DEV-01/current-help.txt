Usage: aatv [--project PATH] [--json] [--device-id ID] [--timeout-ms 1...30000] <command>

Installed helpers use the running app’s managed storage by default. No source
checkout is required. --project PATH is an optional development checkout override
and must match the running app’s selected project.

NUIAK (experimental, off on every launch):
  features status
  features set nuiak on|off
    Changes the running app session only. No device action or control lease.
    GUI startup accepts --nuiak on|off; never restart an app to change state.
    Disabled verification returns feature_disabled before capture/inference.

Audio:
  audio start|start-fresh|start-built-in|status|stop --device-id ID
    Stream modes require active office video; start-built-in does not.
    All modes require existing audio permission. Start returns
    immediately; startup is limited to 10 seconds, then measurement lasts
    30 seconds from first accepted buffer (40-second overall limit).
    Normal streaming prepares audio and video together. audio start/stop
    controls recording only; device disconnect releases both streams.
    No local microphone or local audio playback is enabled by this stream.
    Before a stimulus, match operationID and normally wait for readiness=receiving.
    An idle source may require playback before buffers arrive. The fixture
    runner offers explicit --prime-verified-source for that controlled test;
    waitingForBuffers alone is not evidence of silence or a broken connection.
    Readiness means recent accepted buffers, not audible sound. Abort on
    stalled/inactive. Three seconds without buffers ends capture. Poll for
    stopReason and a finalized artifact; partial recordings are inconclusive.
    permission_denied means existing permission was unavailable;
    attachment_failed means the input/output could not attach. Neither is
    a user cancellation (stop_requested) or proof that the source is silent.
    start-fresh briefly restarts video with audio attached (diagnostic A/B).
    start-built-in explicitly records the single built-in audio-only input,
    without video, camera access, or fallback. Existing permission required.
    start-preview-sink adds a muted audio-preview output for receiver-side
    negotiation diagnostics. It is removed when the bounded sample stops.
    start-native leaves audio output settings at their default for a format
    negotiation comparison. Unsupported live PCM formats are inconclusive.
    start-audio-only stops video and discovers office, then opens an audio-only
    capture graph with raw PCM evidence. Requires existing camera/audio permissions.
    It does not prove audio-only transport on the wire; video is not auto-restored.
    start-fixed-av uses the same isolated diagnostic session with audio and video
    attached before startup. No preview is rendered; frame counts are logged.
    start-fixed-av-hold additionally holds the unchanged graph for 3 seconds
    after recording ends to measure video continuity, then stops the session.
    start-retained records raw PCM + AAC from the normal running preview.
    It intentionally keeps that audio connection after recording stops; later
    start-retained calls reuse it without changing the graph. No recording
    occurs between samples. Disconnect releases it; disconnect before changing
    diagnostic modes. Normal preview now uses the same retained connection.
    start-raw also preserves incoming float32 PCM before AAC encoding, limited
    to 32 MiB. The AudioQualification folder contains operation-matched
    .raw-pcm and         .raw.jsonl files. Require a complete manifest footer; partial
    or failed raw evidence does not invalidate a separately finalized .m4a.

  capture acquire CLIENT_ID --device-id ID
  capture status --device-id ID
  capture events CLIENT_ID --device-id ID
  capture keepalive CLIENT_ID LEASE_ID [ACK_WARNING_SEQUENCE] --device-id ID

    Unidentified GUI captures are not auto-enrolled. resourceContended means
    wait; do not start a colliding session. LEASE-07 hardware handoff is deferred.

  simulator diagnose --simulator-udid UUID
  simulator remote connect --simulator-udid UUID
  simulator remote status|disconnect|snapshot|observe --simulator-udid UUID --session UUID
  simulator remote press --simulator-udid UUID --session UUID --button up|down|left|right|select|back|home|playPause
    One persistent native runner; connect returns starting. Wait for ready before input.
    Each press is sent once. Uncertain replies are never safe to replay.
    Disconnect requests stop; wait for closed before another test on that target.
  simulator teardown-check --simulator-udid UUID --variant session_only|settings|fixture_return
  simulator list
  simulator readiness [--simulator-udid UUID]
  workspace refresh-access
    Refresh the existing folder grant; verify companion access without device input.
  simulator restart --simulator-udid UUID --confirm-exclusive
    Stops this Simulator's test; requires exclusive use and reconciled ownership.
    Never erases devices or resumes navigation. Never retry an uncertain reply.
  simulator reconcile --simulator-udid UUID
    Reconcile retained recovery markers for this Simulator after an interrupted run.

Pairing is not available as an unattended stable command. Use the explicitly
interactive diagnostic pairing flow with a human present.

TVTestRig must be open while CLI or MCP commands are running. The app does not
install a login item or background launch agent.
