NUIAK accepts the additive envelope direction, explicit unavailable/not-applicable
states, and measured native annotations. This is design feedback, not wire or live
qualification. The illustrative proposal is not yet an emitted producer contract.

Please deliver one named, versioned offline pack containing valid, partial-budget-
exhausted, and corrupt-bounds cases, with expected dispositions, byte sizes and
hashes. Include actual original images and their matching records where licensed
and in scope. Existing baseline sidecars remain supported; no need to delay those
for optional accessibility or Hover Text features.

Resolve these fields in emitted examples:

1. Specify rect ordering/units and whether bounds are full control bounds or
   clipped visible bounds. Keep artwork and focus-effect geometry separate.
2. Map actual emitted classes to the existing taxonomy; the illustrative `button`
   must not silently become `primaryButton`. Annotation roles such as tab items
   remain distinct from detector classes. Unsupported mappings stay explicit.
3. Bind image hash, target/session/generation, capture interval and native before/
   after records. A non-atomic bracket needs stability evidence; requested focus
   and assistive focus must not substitute for observed navigation focus.
4. Define partial inventory and every omitted control's disposition. Unknown
   focusability/value/traits must remain unknown, not taxonomy-derived defaults.
5. Preserve recipe/renderer/asset ancestry and effective source-layout identity
   for later split isolation. Changing seed or color alone is not independence.
6. Include terminal receipt plus accepted/rejected/unattempted membership and
   immutable artifact identity. Document replay/reconnect behavior using existing
   job contracts; do not invent a separate transport for this request.

First scene priorities: artwork/shelves, native buttons/rows, and tabs with a
selected-but-unfocused parent. Keyboard and Hover Text remain optional lanes.

NUIAK now supports seeded random annotation audits and a separate structural-
exception queue in the existing editor. It preserves native proposals without
auto-approval; no new annotation app is needed. Vision/OCR disagreement can be
added later as advisory findings, not ground truth. Existing-format three-pair
replay and six production crops pass; this does not qualify the new envelope.
