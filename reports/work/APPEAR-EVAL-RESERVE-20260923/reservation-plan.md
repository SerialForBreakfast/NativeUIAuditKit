# Evaluation reservation contract — requirements frozen, sources unresolved

2026-09-23. Owner: NUIAK architect. This is a pre-capture allocation plan, **not**
an `appearance-evaluation-reservation-v2` admission artifact or frozen corpus.

| Stratum | Available development source | Missing independent coverage |
|---|---|---|
| dense-dark-media | Fixture media_shelf / existing native diagnostics | Two unrelated, unused groups per evaluation role |
| bright-unfocused-artwork | appearance-v1 bright_unfocused/artwork/high_contrast | Two unrelated, unused groups per role; bright native unfocused negatives |
| gray-blank-placeholders | appearance-v1 gray_placeholder/blank_placeholder | Two unrelated, unused groups per role; actual focused/unfocused placeholder controls |
| dock-neighbor-focus | grid_matrix dock; known Home diagnostics | Two unrelated, unused groups per role; neighboring controls retained |
| photos-buttons | Known Photos visual diagnostics only | Actual primary/secondary buttons with observed native focus and geometry; two unrelated unused groups per role |

Roles are `appearance-validation` and `final-challenge`. Each role/stratum needs
at least two connected components with both labels: 20 required role/stratum
slots total, **zero yet source-bound**. This is not necessarily 20 distinct
components: one component may support multiple strata within one role, never
cross roles. No fixed image count substitutes for independent group support.

For each proposed group TTR/NUA records: source revision and renderer/surface,
shared renderer/assets/template/recipe/journey ancestry, prior exposure, exact
target, native label mechanism, supported controls/themes, intended role/strata,
bounded route and safety exclusions. NUA reviews the relationship graph against
all training candidates, retention, known challenges and development diagnostics.
Common code alone does not prove identical data, but source-defined relationships
must justify the declared split rather than rely on names or new seeds.

Known exclusions: all delivered seed7 appearance siblings; prior catalog,
APPEAR-A2/direct pilot/known Home and Photos diagnostics; protected Remotes
challenge remains protected. New captures of the same exposed screen do not
reset prior use. Photos-like collection items cannot fill photos-buttons.

After source binding: serialize exact-target capture; preserve native pre/post
observations, source recipes, PNGs, hashes, geometry and completion/cleanup receipts.
Use existing strict consumer and production 16%/256 crop path. Visually verify
actual buttons and focus effects; exclude requested/predicted labels. Check all
bytes, both labels, expected/captured/rejected targets, decoded duplicates and
transitive cross-partition leakage. Partial failures remain retained and unadmitted.

Freeze exact membership with hash-bound source reviews and v2 reservations only
after admission. Do not score final challenge until protocol and candidate/model
choices are frozen. No threshold, crop or family tuning on final challenge.
