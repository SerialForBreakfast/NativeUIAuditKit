## Findings, in priority order

### 1. Artifact directories need a stable directory rule

Current extension rules exclude JSON, raster images, logs and common arrays, but not dataset TXT labels, cache files, HTML reviews, YAML, SVG, or compressed JSONL. Packet-specific artifact exclusions stop at GLOBAL-REPLAY-146. The six new exclusions in the current `.gitignore` diff therefore do not protect later packets.

Recommended minimal rule, for a separately reviewed policy edit:

```gitignore
# Generated experiment payloads, regardless of format or packet ID.
/reports/work/**/artifacts/
```

This would exclude all 36,119 currently visible artifact paths without hiding the 149 non-artifact candidates. Those artifacts include 36,072 TXT files, 30 HTML files, five YAML, five Markdown, three caches, three SVGs and one GZ file. Largest examples are an 11.2 MB worker variants archive and two approximately 6.4 MB label caches. IOS-REPAIR-165 dominates the count.

Do not solve this with global `*.txt`, `*.yaml`, `*.json`, or `reports/` exclusions: those would hide legitimate schemas, test fixtures, prompts and handoffs. Keep compact reviewed evidence outside `artifacts/`; do not force-add payloads. The existing SYN-05 replay-plan exception is outside this directory pattern.

### 2. Ignore rules do not untrack historical files

`git ls-files -ci --exclude-standard` identifies 41,922 tracked paths matching present rules, including 39,530 under NativeUITrainer. Examples include old dataset labels/annotations, training logs, screenshots and xcresult data. There are also 34 tracked paths containing `/artifacts/` across the index.

This is a **candidate audit list, not a removal list**. It includes `NativeUIAuditKitModels/Sources/NativeUIAuditKitModels/NativeUIDetector_v1.mlpackage.mlmodel`; packaged resources must be checked for intentional use, not swept away. Before any index cleanup, inventory references and required fixtures, preserve useful evidence and verify restoration locations. Then give the maintainer an exact reviewed path list for index-only removal. No broad `git rm -r --cached .`, history rewrite or filesystem deletion.

Removing paths from the next commit does not remove their historical Git objects or reclaim that history's disk space.

### 3. Two unexplained filename changes need reconciliation

The tracked `scripts/sync_shared_status.py` and `scripts/update_nuiak_status.py` are deleted locally. Untracked `scripts/sync_shared_status 2.py` and `scripts/update_nuiak_status 2.py` are byte-identical to their respective HEAD versions.

These are retired fail-closed safety stubs, not new implementations. The renamed sync stub still imports `update_nuiak_status`, so the suffixed filenames do not preserve its import path. Resolve the intended filenames before staging; do not include this as an intentional feature deletion without confirmation. All copies were preserved by this audit.

### 4. Compact operational receipts require selective review
